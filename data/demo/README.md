# Datos de demostración

Todos los nombres, relaciones, categorías y productos de esta carpeta son **ficticios**. Sirven para probar el programa sin conexión y no representan información de la UPC ni de Scienti. Se regeneran con `python3 scripts/build_demo.py`.

Ambos programas abren esta carpeta como demostración de solo lectura. Para conservar cambios, elija otra carpeta mediante **Archivo → Guardar como...** en Python o **Datos → Guardar como** en C++. Los cuatro productos se distribuyen entre 2021 y 2026 para probar las ventanas de dos y cinco años; el primero pertenece a dos grupos, pero se cuenta una sola vez en el total institucional.
